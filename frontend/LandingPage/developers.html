Core Integration

Robust REST API

Our RESTful API provides secure and efficient access to your TX RetailOS data, enabling you to manage sales, inventory, customers, and more.

Authentication

All API requests must be authenticated using an API key. Include your API key in the Authorization header as a Bearer token.

Authorization: Bearer YOUR_SECRET_API_KEY

Sample Request: Get Products

Retrieve a list of all products in your inventory.

GET /api/v1/products
Host: api.txretailos.com
Content-Type: application/json
Authorization: Bearer YOUR_SECRET_API_KEY

Real-time Events

Webhooks

Receive real-time notifications for events in your TX RetailOS account, such as new sales, inventory updates, or customer registrations.

Setting up a Webhook

Configure webhook endpoints in your TX RetailOS dashboard. We'll send HTTP POST requests to your specified URL when events occur.

// Example payload for a 'sale.created' event
{
  "event": "sale.created",
  "timestamp": "2026-07-08T12:34:56Z",
  "data": {
    "sale_id": "sale_xyz789",
    "total_amount": 910.00,
    "currency": "Ksh",
    "items": [
      {
        "product_id": "prod_abc123",
        "quantity": 1,
        "price": 120.00
      }
    ]
  }
}
